# YuisekinAI

A from-scratch pretraining pipeline for a small causal language model.

The goal of this project is to build an AI system that satisfies the
[Open Source AI Definition](https://opensource.org/ai/open-source-ai-definition):
the training data information, the complete training and inference code, and the
model parameters are all made available under OSI-approved terms.
